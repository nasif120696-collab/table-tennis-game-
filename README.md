## ✨ Features

- **Game Modes:**
  - **1 Player:** Challenge CPU with selectable difficulty levels (`Easy`, `Medium`, `Hard`).
  - **2 Players:** Local head-to-head multiplayer on a single screen.
- **Dynamic Physics:**
  - Ball speed increments with paddle hits.
  - Directional deflection based on paddle edge contact points.
- **Controls & Accessibility:**
  - Full keyboard, mouse, and touch drag support for mobile and desktop.
  - Sound effects toggle (Sound ON/OFF).
  - Match pause (`P`), resume, and restart controls.
- **Rule Set:** Official scoring rules (First to 11 points, win by at least 2; serve alternates every 2 points).

## 🕹️ Controls Guide

| Mode | Action | Key / Input |
| :--- | :--- | :--- |
| **Single Player** | Move Paddle | `W` / `S`, `Arrow Keys`, Mouse, or Touch Drag |
| **Two Players** | Player 1 (Left) | `W` (Up) / `S` (Down) or Touch Drag (Left half) |
| | Player 2 (Right) | `↑` (Up) / `↓` (Down) or Touch Drag (Right half) |
| **All Modes** | Serve Ball | `Spacebar` or Tap Table Screen |
| | Pause Game | `P` key or click **Pause** |
